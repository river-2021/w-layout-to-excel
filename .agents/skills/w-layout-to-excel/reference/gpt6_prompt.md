# GPT 仓库布局识别提示词模板

把下面整段发给 GPT（附上仓库平面图）。识别结果 JSON 交给 `normalize.py` 处理。

---

上传的是一张仓库平面图。图中有多排货架，货架一般为背靠背或单排放置；每排货架由多个格子组成，一个格子代表一个货架组；货架之间是通道，货架组之间如果由绿色连线连接则代表通道。请识别图中每个货架组，并严格按以下 JSON 格式输出，不要输出任何其他文字：

```json
{
  "image_size": {"width": 1536, "height": 883},
  "coordinate_system": {"origin": "左上角", "x_direction": "向右", "y_direction": "向下", "unit": "像素"},
  "rack_positions": [
    {
      "id": "R01",
      "x_ranges": [[87, 98], [100, 111]],
      "y_ranges": [[241, 266], [266, 290], [290, 315]]
    }
  ],
  "excluded_regions": [
    {"bbox": [38, 24, 194, 224], "reason": "左上角不规则房间，非货架"}
  ]
}
```

格式说明：每条记录用无损分组表示一条货架排线的位置——`x_ranges` 中每个区间与 `y_ranges` 中每个区间逐一组合，得到一个货架组的边界框 `[x_min, y_min, x_max, y_max]`。上例表示 2 × 3 = 6 个货架组。

要求：

1. `id` 按从左到右（或从上到下）R01、R02… 连续编号；背靠背的两列（或两行）属于同一条货架排线，放在同一个 id 里，即深度方向并列的区间写进同一个记录。
2. 排线延伸方向上被通道断开的部分，仍留在同一记录的 ranges 里（通道会表现为区间之间的大空隙，下游会自动拆分）。
3. 坐标为像素近似值，左上角为原点，x 向右、y 向下；ranges 按起点从小到大排列，`起点 < 终点`。
4. 识别不确定的货架排：加 `"confidence": "较低"` 和 `"review_reason": "原因"` 字段；末端格子被图片边缘截断时加 `"last_y_range_truncated": true`。
5. 通道、设备区、房间、图框、文字等不算货架，写入 `excluded_regions` 并说明理由。

---

## 备注（给 skill 使用者，不用发给 GPT）

- `normalize.py` 同时兼容本分组格式与扁平 `racks[].cells`（逐格 bbox）格式，自动检测。
- 分组格式**隐含满格假设**：x_ranges × y_ranges 的笛卡尔积会把缺格补齐。若图纸明显有缺格（空洞、被设备遮挡的格位），改用下面的扁平格式重跑 GPT，缺格才能如实表达。
- 扁平格式 token 开销大（同样约 1000 格的图：分组 ≈ 3.5k tokens，扁平缩进格式 ≈ 27k tokens，可能超出模型单次输出上限被截断）。**格子数 ≥ 300 的图优先用分组格式**；小图或确有缺格时再用扁平格式（可要求紧凑输出降低 token）。

### 扁平格式模板（备选，缺格场景/小图用）

```json
{
  "image_size": {"width": 1536, "height": 883},
  "racks": [
    {"id": "R01", "orientation": "V", "confidence": 1.0,
     "cells": [{"x0": 87, "y0": 241, "x1": 98, "y1": 266}]}
  ],
  "excluded_regions": []
}
```
`orientation`：排线竖向延伸填 `"V"`，横向填 `"H"`；一格一条记录，图上有几个格写几条，不要合并。
